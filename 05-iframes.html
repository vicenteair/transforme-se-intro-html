O que é um iframe?

Um iframe (inline frame) é um elemento HTML que permite incorporar outra página HTML dentro da página atual.

Entendendo o elemento iframe

  • O elemento iframe é usado para incorporar outra página HTML dentro da página atual.
  • O atributo src especifica o URL da página a ser incorporada.
  • Os atributos width e height definem o tamanho do iframe.
  • O atributo title fornece uma descrição do conteúdo do iframe para acessibilidade.

Incorporando o Youtube

Explicando tags do iframe do youtube

  • O atributo src contém o link do vídeo do YouTube que será incorporado.
  • O atributo allowfullscreen permite que o vídeo seja exibido em tela cheia.
  • O atributo frameborder define a largura da borda do iframe (0 significa sem borda).
  • O atributo allow especifica permissões para o conteúdo do iframe, como autoplay e clipboard-write.
  • O atributo referrerpolicy define como o referer é enviado ao carregar o iframe.
  • O atributo encrypted-media permite a reprodução de mídia criptografada.
  • O atributo gyroscope permite que o iframe acesse os dados do giroscópio do dispositivo.
  • O atributo picture-in-picture permite que o vídeo seja exibido em uma janela flutuante enquanto o usuário navega em outras páginas.
  • O atributo web-share permite que o conteúdo do iframe seja compartilhado usando a API de compartilhamento da web.
  • O atributo title fornece uma descrição do conteúdo do iframe para acessibilidade.
  • O atributo referrerpolicy define como o referer é enviado ao carregar o iframe.
  • O atributo loading define como o iframe é carregado (lazy para carregamento lento).
