Conhecendo Imagens no HTML

Entendendo o elemento img

  • O elemento img é usado para inserir imagens em uma página HTML.
  • O atributo src especifica o caminho da imagem.
  • O atributo alt fornece um texto alternativo para a imagem.
  • Os atributos width e height definem o tamanho da imagem.

Sobre os diferentes tipos de imagens

Existem diferentes tipos de imagens que podem ser utilizadas em uma página HTML, cada uma com suas características e usos específicos. Alguns dos tipos mais comuns incluem:

  • JPEG (Joint Photographic Experts Group): Ideal para fotografias e imagens com muitas cores. Possui boa compressão, mas pode perder qualidade.
  • PNG (Portable Network Graphics): Suporta transparência e é ideal para imagens com áreas transparentes ou gráficos. Mantém a qualidade da imagem, mas pode ter um tamanho de arquivo maior.
  • GIF (Graphics Interchange Format): Suporta animações e é ideal para imagens simples com poucas cores. No entanto, possui uma paleta de cores limitada.
  • SVG (Scalable Vector Graphics): Formato vetorial que permite redimensionamento sem perda de qualidade. Ideal para logotipos, ícones e gráficos.
  • WebP: Formato moderno que oferece boa compressão e qualidade. Suporta transparência e animações, sendo uma alternativa eficiente para imagens na web.
  • AVIF: Formato de imagem moderno que oferece alta compressão e qualidade. Suporta transparência e é eficiente para imagens na web.
