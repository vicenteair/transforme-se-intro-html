Intrdução

HTML é uma linguagem de marcação utilizada para estruturar e apresentar conteúdo na web. Realizamos essa marcação através de elementos como títulos, parágrafos, listas, imagens, links e muito mais.

Elementos HTML

Títulos

Os elementos h1 a h6 são utilizados para criar títulos e subtítulos em uma página web. O h1 é o título principal, seguido pelos demais em ordem de importância.

Parágrafos

O elemento p é utilizado para criar parágrafos de texto em uma página web. Ele é um dos elementos mais comuns e importantes do HTML, permitindo a organização e a formatação do conteúdo textual.

Conclusão

Os elementos textuais no HTML são fundamentais para a estruturação e apresentação de conteúdo na web. Títulos, parágrafos e outros elementos permitem criar páginas bem organizadas e acessíveis.
