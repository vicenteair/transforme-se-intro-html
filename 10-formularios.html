Formulários em HTML

O que são formulários?

Formulários em HTML são elementos que permitem que os usuários insiram dados em um formulário e enviem esses dados para um servidor.

Criando um formulário básico

  • < label >: Representa um rótulo para o elemento de entrada.
  • for: Atributo que associa o rótulo ao elemento de entrada correspondente.
  • id: Atributo que identifica exclusivamente o elemento de entrada.
  • type: Atributo que especifica o tipo de elemento de entrada.
