Sobre o elemento de âncora - HTML

O elemento de âncora (<a>) é usado para criar links em uma página HTML. Ele permite que os usuários naveguem para outras páginas, seções da mesma página ou recursos externos.

  • O atributo href especifica o URL do destino do link.
  • O atributo target define onde o link será aberto (por exemplo, _blank para abrir em uma nova aba).
  • O conteúdo entre as tags de abertura e fechamento do elemento <a> é o texto clicável do link.
  • O atributo blank é usado para abrir o link em uma nova aba.
  • O atributo self é usado para abrir o link na mesma aba.
  • O atributo parent é usado para abrir o link na aba pai.
  • O atributo top é usado para abrir o link na aba superior.
  • O atributo rel pode ser usado para especificar a relação entre o elemento atual e o recurso referenciado.
